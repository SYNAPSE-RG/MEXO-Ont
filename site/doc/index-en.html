Abstract

MEXO is an OWL ontology for representing metaheuristic algorithms, benchmark problems and instances, experiment configurations, parameters, computational budgets, stopping criteria, runs, and performance results. It is complemented by a SKOS taxonomy of metaheuristic algorithms and families.

Introduction back to ToC

The MEXO documentation is generated automatically with WIDOCO from the canonical Turtle sources maintained in the SYNAPSE-RG/MEXO-Ont repository. MEXO uses the persistent namespace https://w3id.org/mexo/.

MEXO: Description back to ToC

MEXO provides a machine-interpretable vocabulary for documenting and comparing metaheuristic optimization experiments. The publication graph combines the OWL ontology with the associated SKOS taxonomy so that WIDOCO can document the formal model and its controlled algorithm vocabulary together.
